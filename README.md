# Resell-Note

仕入れ前の利益試算、商品・在庫・販売実績の記録を行う日本語Webアプリです。

## 起動方法

WindowsではZIPを展開し、`START_HERE.bat` をダブルクリックします。既定のブラウザーで起動します。インストール、サーバー、アカウント、インターネット接続は不要です。`index.html` を直接開いても利用できます。

## はじめての使い方

画面上部の「使い方」から、利益試算、仕入れ候補の保存、在庫への更新、販売後の実績更新、CSVの取込・出力を順に確認できます。入力欄やボタンにマウスを重ねると説明が表示されます。手元に置ける詳しい説明は [使い方ガイド.txt](使い方ガイド.txt) を参照してください。

## データとプライバシー

アプリは外部APIや外部フォントを読み込まず、CSPで外部ネットワーク接続を禁止しています。商品データは利用したブラウザーの `localStorage` にだけ保存され、インターネットへ送信・保存されません。GitHubにはアプリのソースコードとガイドのみを置き、商品データは登録しません。他の端末やブラウザーには同期されないため、画面上部のCSV出力で定期的にバックアップしてください。CSV取込は商品データを追加し、既存データは残します。

表示する利益は入力値から計算する概算です。税金、返品、値下げ、保管料等は含みません。販売先やカテゴリごとの手数料率を確認して入力してください。

商品一覧では行クリックによる詳細編集に加え、複数商品の情報を表形式でまとめて編集できます。販売済み商品を手動でアーカイブすると、通常一覧から過去データ一覧へ移動します。削除はアーカイブ専用CSVを出力した後に限ります。

同じ商品のまとめ仕入れは1件として登録し、数量と1個あたりの金額を入力できます。商品を「候補」から「在庫」へ移す時や「在庫」から「販売済み」にする時に、数量の一部だけを指定できます。残りの数量は元の状態に残り、別価格で売れた分も分けて記録できます。

ダッシュボードでは販売日を基準に、円・棒・折れ線グラフを選び、売上、利益、仕入れ原価、数量、商品件数を月・週・カテゴリ・状況ごとに集計できます。表示グラフ数は1〜4個で選べます。販売日が記録されていない以前の販売データはグラフに含めず、その件数を案内します。

## バージョンアップ時のデータ

アプリは同じブラウザーの `localStorage` キーを維持し、既存データに数量がない場合は1個として読み込みます。ZIPを同じフォルダーへ展開して同じブラウザーで起動すれば、通常は以前のデータを引き続き利用できます。ただしブラウザーは `file://` の保存領域の扱いを定めていないため、展開先フォルダーを変えたり閲覧データを消したりすると引き継がれない場合があります。バージョンアップ前後にCSVを保存してください。

## ハーネス開発

要件とガードレールは [`harness/requirements.md`](harness/requirements.md)、受け入れ条件は [`harness/acceptance.md`](harness/acceptance.md)、変更手順は [`harness/workflow.md`](harness/workflow.md) を参照してください。変更前に `sh scripts/verify.sh` を実行します。GitHub Actionsでハーネス確認とWindows向けポータブルZIP作成を行います。
