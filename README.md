# Resell-Note

仕入れ前の利益試算、商品・在庫・販売実績の記録を行う日本語Webアプリです。

## 起動方法

WindowsではZIPを展開し、`START_HERE.bat` をダブルクリックします。既定のブラウザーで起動します。インストール、サーバー、アカウント、インターネット接続は不要です。`index.html` を直接開いても利用できます。

## はじめての使い方

画面上部の「使い方」から、利益試算、仕入れ候補の保存、在庫への更新、販売後の実績更新、CSVバックアップを順に確認できます。入力欄やボタンにマウスを重ねると説明が表示されます。手元に置ける詳しい説明は [使い方ガイド.txt](使い方ガイド.txt) を参照してください。

## データとプライバシー

アプリは外部APIや外部フォントを読み込まず、CSPで外部ネットワーク接続を禁止しています。商品データは利用したブラウザーの `localStorage` にだけ保存され、インターネットへ送信・保存されません。GitHubにはアプリのソースコードとガイドのみを置き、商品データは登録しません。他の端末やブラウザーには同期されないため、画面上部のCSV出力で定期的にバックアップしてください。

表示する利益は入力値から計算する概算です。税金、返品、値下げ、保管料等は含みません。販売先やカテゴリごとの手数料率を確認して入力してください。

同じ商品のまとめ仕入れは1件として登録し、数量と1個あたりの金額を入力できます。数量分の在庫原価・売上・利益を集計します。この版では販売済みへの変更は登録数量全体を一括販売した扱いです。

## バージョンアップ時のデータ

アプリは同じブラウザーの `localStorage` キーを維持し、既存データに数量がない場合は1個として読み込みます。ZIPを同じフォルダーへ展開して同じブラウザーで起動すれば、通常は以前のデータを引き続き利用できます。ただしブラウザーは `file://` の保存領域の扱いを定めていないため、展開先フォルダーを変えたり閲覧データを消したりすると引き継がれない場合があります。バージョンアップ前後にCSVを保存してください。

## ハーネス開発

要件とガードレールは [`harness/requirements.md`](harness/requirements.md)、受け入れ条件は [`harness/acceptance.md`](harness/acceptance.md)、変更手順は [`harness/workflow.md`](harness/workflow.md) を参照してください。変更前に `sh scripts/verify.sh` を実行します。GitHub Actionsでハーネス確認とWindows向けポータブルZIP作成を行います。
